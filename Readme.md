# TCP Price Feed Simulator

A basic TCP-based price feed simulator written in Rust.

This project simulates a server streaming mock price updates to connected clients over TCP sockets.
Built for learning low-level networking, socket programming, and client-server communication in Rust.

## Goals

* Understand TCP socket communication
* Learn client-server architecture
* Practice Rust networking APIs
* Explore stream-based data transfer
* Build familiarity with concurrent connection handling

## Current Status

Initial project setup and networking experimentation.

## Tech Stack

* Rust
* std::net
* TCP sockets

## Planned Features

* TCP server
* TCP client
* Real-time mock price feed
* Multiple client handling
* Concurrent connections
* Configurable symbols and intervals

## Run

```rust
cargo run
```

## Notes

This project is focused on learning systems programming and networking concepts in Rust.
